# Gemma 4 Integration — VibeUp

## Architecture
VibeUp runs a multi-agent pipeline powered by Gemma 4 where specialized 
autonomous agents plan, reason, use tools, retain memory, and execute 
complex financial research workflows.

## Agent Roster
| Agent | Model | Task | Memory |
|-------|-------|------|--------|
| Signal Agent | Gemma 4 (`gemma-4-31b-it`) | ACT/WATCH/NOISE classification | No |
| Research Agent | Gemma 4 (`gemma-4-31b-it`) | RAG synthesis over SEBI filings | No |
| Sentiment Agent | Gemma 4 (`gemma-4-31b-it`) | Retail + news sentiment scoring | No |
| Risk Agent | Gemma 4 (`gemma-4-31b-it`) | Suitability + concentration checks | Yes |
| GemmaBot (Debate) | Gemma 4 (`gemma-4-31b-it`) | Crowd sentiment in debate arena | No |
| Orchestrator | Gemma 4 (`gemma-4-31b-it`) | Plans + synthesizes all agents | Yes |
| Quant Agent | Claude Sonnet 4.6 | Mathematical stress modeling | No |

## Memory System
`AgentMemory` table persists per-user context across sessions:
`portfolio_summary`, `archetype`, `behavioral_flags`, `recent_actions`,
`signal_history`. Injected into every Gemma agent prompt.

## Tool Use
- NSE API (price, volume, options chain)
- yfinance (historical OHLCV)
- pgvector RAG (SEBI filings, earnings transcripts)
- RSS scrapers (ET, Moneycontrol)
- Reddit scraper (r/IndiaInvestments)
- SQLite (portfolio, memory)

## Where Gemma Appears in UI
- Signal Feed: every card classified by Gemma Signal Agent
- AUREX Chat & Voice Call: all responses via Gemma (simple + orchestrated) with live voice call overlay & TTS
- Debate Arena: GemmaBot as fourth parallel streaming agent
- Vibe Picks: thesis bullets generated by Research Agent
- Regret Simulator: tagline generated by Gemma
- Vibe Wrapped: all narrative copy generated by Gemma
- ModelBadge: live attribution shown on every AI-generated element

## Gemma 4 as Core — Not a Feature
Gemma 4 handles: signal intelligence, research synthesis, sentiment 
analysis, risk assessment, conversational AI, debate participation, 
narrative generation, and cross-session memory. Claude handles only 
mathematical computation (stress test, CAGR, Monte Carlo). If Gemma 
were removed, the product would cease to function. That is the 
definition of Gemma as a core component.
